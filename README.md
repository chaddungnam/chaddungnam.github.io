# chaddungnam.github.io

House Duck의 공개 웹사이트(houseduck.in)를 GitHub Pages로 호스팅하는 저장소입니다.
개인정보처리방침, 이용약관, 고객지원, `app-ads.txt` 같은 공개 페이지만 둡니다.

이 저장소는 누구나 볼 수 있습니다. 게임 소스, 키, 비밀번호, 서명 키, 데이터베이스,
사용자 데이터, 내부 설계·운영 문서는 넣지 않습니다.

커밋 전에 아래 검사를 실행합니다.

```bash
scripts/check_public_repo.sh
scripts/check_legal_site.sh
```

GitHub에서도 같은 검사를 자동 실행합니다. 보안 문제 제보 절차는 `SECURITY.md`를 따릅니다.
