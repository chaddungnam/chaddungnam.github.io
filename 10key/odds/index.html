딸깍 서바이벌에는 확률형 아이템이 포함되어 있습니다. 아래는 게임 안 상점 > 모듈 > 확률 화면과 같은 내용입니다.

모듈 뽑기 (캡슐형)

  • 대상: Android·iOS 앱. 고급부품 1개로 모듈 1개를 뽑습니다.
  • 고급부품 가격: 보석 30개(1회), 보석 300개(10회). 보석은 게임 플레이로 얻거나 인앱 구매로 살 수 있습니다.
  • 모든 모듈의 확률이 같습니다. 보장(천장) 장치, 기간 한정 확률, 조건에 따라 바뀌는 확률은 없습니다. 10회 뽑기는 1회 뽑기를 10번 한 것과 같습니다.

English

10key Survival contains random items. This page shows the same odds as the in-game SHOP > MODULES > ODDS screen.

Module draw

  • Android and iOS apps. One Rare Part opens one module.
  • Rare Part price: 30 gems (1 draw), 300 gems (10 draws). Gems are earned by playing or bought in the app.
  • Every module has the same chance. There is no pity counter, no limited-time odds and no odds that change with conditions. A 10-draw is the same as ten 1-draws.

Duplicates

A module you already own goes up one grade, with no chance involved: N → R → SR → SSR → UR. A duplicate after UR becomes 120 scrap.

Changes

Any change to these odds is announced in the in-game notice and on this page before it takes effect. Contact: support@houseduck.in
