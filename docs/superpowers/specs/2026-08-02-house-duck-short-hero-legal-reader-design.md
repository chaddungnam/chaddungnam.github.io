# House Duck 낮은 화면 히어로·공통 문서 리더 디자인 명세

## 목표

1. macOS Dock이 보이는 `2048×684` 브라우저에서도 House Duck 메인의 첫 문구, 설명, 두 버튼,
   오리 그래픽이 첫 화면 안에 모두 보여야 한다.
2. Quirky Ball 이용약관·개인정보처리방침·계정삭제·고객지원 페이지를 House Duck 브랜드와
   어울리는 읽기 쉬운 문서 화면으로 통일한다.
3. 이후 담당 스레드는 공통 CSS나 화면 구조를 건드리지 않고 본문 문구와 시행일만 바꿀 수 있어야 한다.

## 승인 근거와 선택한 방향

- 기존 승인 방향인 `Playful Editorial Toy Lab`과 현재 팔레트·폰트·CSS 오리 마크를 유지한다.
- 사용자는 디자인 선택을 위임하고 바로 구현하도록 요청했다.
- Superdesign에서 현재 화면을 재현한 뒤 두 방향씩 비교했다.
  - 히어로는 폭만 줄이는 안보다 **뷰포트 높이에 맞춘 편집형 압축**을 선택한다.
  - 문서는 섹션별 카드 나열보다 **고정 목차 + 흰 종이 본문**을 선택한다.
- Superdesign 프로젝트: `77f86030-da4f-4736-95f3-15afff99d5bc`
- 선택한 참고 초안:
  - 낮은 화면 히어로: `d40ea22d-abbc-49e6-a85a-b12efade5311`
  - 문서 리더: `01ef3eac-d05a-463a-af63-07361f706dbb`
- 생성 초안의 외부 Tailwind·Google Fonts·Iconify는 참고용일 뿐이며 실제 사이트에는 넣지 않는다.

## 범위

### 메인 히어로

- `index.html`과 `index_en.html`의 기존 마크업과 문구를 유지한다.
- `assets/brand-site.css`에 데스크톱 낮은 높이 전용 규칙을 추가한다.
- `min-width: 901px`이면서 `max-height: 820px`인 화면에서 다음을 적용한다.
  - 히어로 높이는 헤더를 제외한 `100dvh` 안으로 제한한다.
  - 제목 크기, 제목 여백, 설명 행간, 버튼 여백, 오리 카드 높이를 뷰포트 높이에 맞춰 줄인다.
  - `SMALL GAMES.`와 `BIG PERSONALITY.`는 각각 한 줄이 되어 전체 제목이 두 줄로 보이게 한다.
- 일반 높이 데스크톱과 기존 모바일 디자인은 현재 구성을 유지한다.

### 공통 문서 화면

다음 실제 콘텐츠 페이지를 같은 문서 시스템으로 통일한다.

- 개인정보처리방침: `quirky-ball/privacy/{ko,en,de,ja}.html`
- 이용약관: `quirky-ball/terms/{ko,en,de,ja}.html`
- 계정삭제: `quirky-ball/privacy/delete_{ko,en,de,ja}.html`
- 언어 선택: `quirky-ball/privacy/index.html`, `quirky-ball/privacy/delete.html`,
  `quirky-ball/terms/index.html`
- 고객지원: `support/index.html`

루트 `privacy/*.html`, `terms/*.html`은 기존 정식 Quirky Ball 문서로 이동시키는 호환 리디렉션이므로
경로와 이동 동작을 유지한다.

## 문서 정보 구조

1. **건너뛰기 링크**
   - 키보드 사용자가 바로 본문으로 이동할 수 있다.
2. **컴팩트 브랜드 헤더**
   - CSS 오리 마크, House Duck 홈, 문서 종류, 언어 칩을 제공한다.
3. **문서 히어로**
   - 문서 종류, Quirky Ball, 제목, 시행일만 표시한다.
   - 새로운 법률 설명이나 약속 문구는 임의로 추가하지 않는다.
4. **자동 목차**
   - 데스크톱에서는 왼쪽에 고정한다.
   - `assets/legal-site.js`가 본문 `h2[id]`에서 목차를 자동 생성하므로 제목을 바꾸면 목차도 함께 바뀐다.
   - JavaScript가 꺼져도 본문은 완전히 읽을 수 있다.
5. **흰 종이 본문**
   - 본문 폭은 최대 `720px`, 충분한 행간과 문단 간격을 사용한다.
   - 표는 자체 컨테이너에서만 가로 스크롤하고 페이지 전체는 넘치지 않는다.
6. **문서 푸터**
   - 관련 문서, 고객지원, House Duck 홈 링크를 제공한다.

## 유지보수 구조

- `assets/legal-site.css`: 모든 문서·고객지원·언어 선택 페이지의 유일한 시각 정본
- `assets/legal-site.js`: 현재 연도와 `h2[id]` 기반 목차 생성만 담당
- 각 HTML에는 다음 경계를 주석으로 명시한다.
  - `문서 메타데이터`: 제목·시행일·언어 링크
  - `문서 본문 시작/끝`: 실제 정책 문구
- 문서 본문은 JSON이나 JavaScript 문자열로 옮기지 않고 시맨틱 HTML로 유지한다.
- 공통 레이아웃 변경은 CSS/JS에서, 정책 문구 변경은 해당 언어 HTML의 본문 경계 안에서만 수행한다.
- 새 프레임워크, 패키지 관리자, 빌드 단계, 외부 폰트·아이콘·추적 코드는 추가하지 않는다.

## 계정삭제와 고객지원

- 계정삭제 페이지는 앱 내 `설정 → 계정 삭제` 3단계를 가장 먼저 보여준다.
- 이메일 요청은 두 번째 방법으로 분리하고 기존 `support@houseduck.in` CTA를 유지한다.
- 삭제·보관 데이터 표의 기존 문구와 날짜는 변경하지 않는다.
- 고객지원은 같은 브랜드 헤더와 문서 폭을 사용하고, 이메일 카드는 코랄 CTA, FAQ는 접기 기능 없는
  단순 섹션으로 유지해 검색·복사·인쇄가 쉽도록 한다.

## 모바일·접근성·인쇄

- `390×844`에서 페이지 가로 스크롤이 없어야 한다.
- 문서 목차는 본문 위의 기본 `details`로 배치하고, 펼치면 짧은 섹션 링크 목록이 보이게 한다.
- 표 셀 글자를 과도하게 줄이지 않고 표 컨테이너만 가로 스크롤한다.
- 모든 링크·버튼은 최소 `44px` 터치 영역과 `:focus-visible` 외곽선을 제공한다.
- `prefers-reduced-motion`에서는 부드러운 스크롤과 전환을 끈다.
- 인쇄 시 브랜드 내비게이션·목차·배경·그림자를 숨기고 검은 글자의 단일 문서로 출력한다.

## 콘텐츠 안전 범위

- 이번 작업은 법률 검토나 문구 개정이 아니다.
- 한국어·영어·독일어·일본어의 기존 법률 본문, 시행일, 버전, 이메일, 데이터 보관기간을 유지한다.
- 링크 구조와 Google Play 정책용 계정삭제 공개 URL을 유지한다.
- 문구 변경이 필요해 보이는 항목은 임의 수정하지 않고 별도 법률 검토 대상으로 남긴다.

## 검증 기준

1. 현재 `2048×684`에서 히어로가 약 `310px` 초과하는 실패를 자동 재현한다.
2. 수정 후 `2048×684`, `1440×700`, `1440×900`에서 설명·두 CTA·오리 카드가 모두 첫 화면 안에 있다.
3. 문서 계약 검사는 12개 현지화 문서, 3개 언어 선택 페이지, 고객지원이 공통 CSS/JS와 시맨틱
   본문 경계를 사용하는지 확인한다.
4. 문서 페이지에 인라인 `<style>`과 외부 런타임 의존성이 없어야 한다.
5. 한국어 개인정보처리방침, 독일어 이용약관, 한국어 계정삭제, 고객지원을 데스크톱과 `390×844`
   실제 Chrome에서 캡처해 제목·본문·표·언어 링크·푸터의 겹침과 잘림을 확인한다.
6. 기존 `check_brand_site.sh`, `check_policy_content.sh`, `check_public_repo.sh`,
   `check_analytics_dashboard.sh`, `test_pulse_model.js`가 모두 통과해야 한다.

## 제외 범위

- 법률 문구의 정확성 판단이나 법률 자문
- 게임 클라이언트의 계정삭제 동작 변경
- Supabase 데이터·인증·삭제 함수 변경
- 새로운 언어 추가
- Google Play 출시 링크 추가
