# House Duck Pulse 쉬운 시각 대시보드 설계

## 목표

비개발 운영자가 첫 화면을 3초만 보고도 `좋아요 / 지켜봐요 / 고쳐야 해요 / 판단 대기` 중
현재 상태와 오늘 할 일 한 가지를 이해한다. 기존 Google 로그인, 프로젝트 선택, 기간·스토어 필터,
Supabase 집계 계약은 바꾸지 않는다.

## 첫 화면 구조

1. **오리 진단과 신호등**: House Duck 오리 얼굴, 상태 신호등, 상태 점수, 한 문장 진단을 한 카드에 둔다.
2. **오늘 할 일**: 가장 나쁜 핵심 지표 하나만 골라 쉬운 행동 문장으로 제안한다.
3. **네 가지 질문**: `오래 하나?`, `끝까지 하나?`, `다시 오나?`, `광고는 적당한가?`만 크게 표시한다.
4. **압축 흐름 그래프**: `들어옴 → 게임 시작 → 게임 완료 → 광고 본 사람`을 사람 수와 단계 비율로 표시한다.
5. **7일 변화 그래프**: 기존 일별 캔버스를 작게 유지해 방향성을 한눈에 본다.
6. **운영자 상세보기**: 시간대, 종료 유형, 광고 이벤트, 플랫폼 비교, 일별 표는 기본 접힘으로 이동한다.

## 상태 규칙

- 표본 기준: 세션 30회 미만이면 핵심 평가는 `판단 대기`로 표시한다.
- 오래 하나: 평균 한 판 180초 이상 `좋아요`, 60초 이상 `지켜봐요`, 그 미만 `고쳐야 해요`.
- 끝까지 하나: 완료율 65% 이상 `좋아요`, 45% 이상 `지켜봐요`, 그 미만 `고쳐야 해요`.
- 다시 오나: D1 20% 이상 `좋아요`, 10% 이상 `지켜봐요`, 그 미만 `고쳐야 해요`. 값이 없으면 `판단 대기`.
- 광고 부담: 플레이어당 3회 이하 `부담 적음`, 5회 이하 `지켜봐요`, 그 초과 `너무 많아요`.
- 색만으로 판단하지 않도록 모든 상태에 아이콘과 한글 상태 문구를 함께 표시한다.

## 데이터 해석 안전성

- 흐름 그래프는 서버가 반환한 이벤트별 고유 사용자 수를 사용하고, `기간 중 각 행동을 한 사람`이라고 설명한다.
- 광고 단계는 게임 완료 직후의 엄격한 순차 전환을 뜻하지 않는다.
- 테스트 광고는 광고 흐름에는 포함되지만 예상 수익에서는 제외된다는 기존 설명을 유지한다.
- 사람이 적을 때 좋음·나쁨을 단정하지 않고 필요한 세션 수를 알려준다.

## 반응형·접근성

- 1180px 데스크톱에서는 진단, 네 지표, 흐름과 7일 변화가 첫 화면 중심에 들어온다.
- 720px 이하에서는 카드가 한 열로 쌓이고 상세보기는 그대로 접힌다.
- 본문과 상태 문구는 14px 미만으로 줄이지 않는다.
- 신호등과 그래프 단계에는 텍스트 라벨을 유지한다.

## 검증

- 순수 상태 계산을 Node 테스트로 검증한다.
- HTML 계약 검사, JavaScript 문법 검사, 공개 저장소 보안 검사를 통과시킨다.
- 로그인 없이도 샘플 데이터로 대시보드를 렌더하는 로컬 QA 문서를 만들어 데스크톱과 모바일 캡처를 확인한다.
