# House Duck 브랜드 사이트 리뉴얼 디자인 명세

## 목표

`houseduck.in`을 정책 링크 모음처럼 보이는 임시 페이지에서, House Duck의 취향과 신뢰를
5초 안에 전달하는 독립 게임 스튜디오 사이트로 바꾼다. Quirky Ball 페이지는 동일한 브랜드
언어를 사용하면서 첫 대표작의 재미와 출시 상태를 명확히 설명한다.

## 승인된 방향

- 최우선 주인공은 Quirky Ball이 아니라 **House Duck 브랜드**다.
- 단일 시각 방향은 `Playful Editorial Toy Lab`이다.
- 큰 편집형 타이포, 비대칭이지만 정돈된 그리드, 촉감 있는 카드와 버튼을 사용한다.
- 기존 Quirky Ball 로고, 대표 이미지, 스크린샷, 로컬 폰트를 재사용한다.
- 외부 프레임워크, 외부 폰트, 외부 아이콘 CDN은 추가하지 않는다.
- 가짜 팀원, 수상 이력, 리뷰, 설치 수, 평점, 출시 완료 상태를 만들지 않는다.

## 공통 디자인 시스템

- 배경: 크림 `#F6F0E0`
- 카드: 페이퍼 `#FFFDF7`
- 주 텍스트/다크 섹션: 네이비 `#172541`
- 주 행동: 코랄 `#F25F4C`
- 보조: 틸 `#2FB7AA`, 골드 `#F4C84A`
- 제목: Montserrat 800–900, 한국어 포인트만 Do Hyeon
- 카드 반경: 24–36px, 버튼 최소 높이 48px
- 콘텐츠 최대 폭: 1180px
- 키보드 포커스는 3px 틸 외곽선으로 항상 보인다.
- `prefers-reduced-motion`에서는 이동·부유 애니메이션과 부드러운 스크롤을 끈다.

## House Duck 메인 구조

1. 고정 내비게이션
   - CSS 오리 마크 + `HOUSE DUCK`
   - `Games`, `Studio`, `Support`, `KR / EN`
   - 모바일에서는 메뉴 버튼으로 핵심 링크를 열고 닫되, 가로 스크롤 없이 키보드와 Escape 키로 조작할 수 있게 한다.
2. 브랜드 히어로
   - `SMALL GAMES. BIG PERSONALITY.` 대형 문구
   - 독일의 작은 독립 게임 스튜디오라는 짧고 정직한 설명
   - CSS 오리 마크와 낮은 강도의 장식 구슬
   - 첫 게임으로 이동하는 단일 코랄 CTA
3. 대표작
   - Quirky Ball 대표 이미지와 실제 로고
   - 출시 준비 상태와 짧은 게임 설명
   - Quirky Ball 상세 페이지 이동
4. 세 가지 원칙
   - 누구나 쉽게 시작
   - 익숙한 규칙 속 뜻밖의 재미
   - 플레이어의 시간과 선택 존중
5. 스튜디오 노트와 마감 CTA
   - 독일 기반 1인 독립 스튜디오임을 간결하게 표시
   - 고객지원·약관·개인정보 링크 유지

## Quirky Ball 페이지 구조

1. House Duck 공통 내비게이션과 스튜디오 복귀 링크
2. 분할 히어로
   - 실제 Quirky Ball 로고와 대표 이미지
   - `같은 구슬, 더 쿼키하게.` 메시지
   - `Google Play 출시 준비 중` 상태를 사실 그대로 표시
3. 세 동사로 설명하는 핵심 루프
   - `DROP`, `MERGE`, `OUTSMART`
4. 캐릭터·경쟁 기능
   - 조커, 폭탄 룰렛, 글로벌/국가 랭킹
5. 실제 스크린샷 갤러리
   - 홈, 게임플레이, 하드 모드, 조커, 폭탄, 랭킹 6장
   - 세로 기기 프레임 형태, 모바일에서는 한 열
6. House Duck 소유 표시와 출시 상태 CTA
7. 이용약관·개인정보·고객지원 푸터

## 언어와 콘텐츠

- 한국어 `index.html`과 영어 `index_en.html`은 구조와 시각 품질이 동일해야 한다.
- 브라우저 언어 자동 이동은 유지하되 `?lang=ko` 또는 사용자가 언어 링크를 눌러 진입한 경우
  선택한 페이지를 다시 강제로 이동시키지 않는다.
- 영어 페이지는 한국어 페이지의 축약판이 아니라 같은 섹션을 자연스러운 영어로 제공한다.
- Google Play 실제 URL이 저장소에서 확인되기 전에는 링크를 만들지 않고 출시 준비 상태만 표시한다.

## 파일 구조

- `assets/brand-site.css`: 네 페이지가 공유하는 전체 디자인과 반응형 규칙
- `assets/brand-site.js`: 연도 표시, 모바일 내비게이션, 선택 언어 보존, 화면 진입 표시만 담당
- `index.html`, `index_en.html`: House Duck 현지화 HTML
- `quirky-ball/index.html`, `quirky-ball/index_en.html`: Quirky Ball 현지화 HTML
- `scripts/check_brand_site.sh`: 링크·필수 섹션·접근성·외부 의존성·언어 동등성 계약 검사

## 접근성·성능·보안

- 시맨틱 `header`, `nav`, `main`, `section`, `footer`를 사용한다.
- 장식 이미지는 빈 대체 텍스트와 `aria-hidden`, 콘텐츠 이미지는 의미 있는 `alt`를 사용한다.
- 모든 클릭 요소는 키보드로 접근 가능하고 최소 44px 터치 영역을 갖는다.
- 390px에서 가로 스크롤이 없어야 한다.
- 모든 이미지에 고정 비율 또는 크기를 제공해 레이아웃 흔들림을 줄인다.
- 로컬 폰트와 이미지 이외의 런타임 네트워크 의존성은 금지한다.
- 인라인 비밀값, Supabase 키, 분석 코드, 외부 추적 스크립트를 추가하지 않는다.

## 검증 기준

1. `scripts/check_brand_site.sh`가 네 페이지의 공통 CSS/JS, 내비게이션, 언어 링크, 법적 링크,
   필수 섹션, 이미지 경로, 외부 CDN 부재를 검사해 통과한다.
2. 기존 `check_public_repo.sh`, `check_policy_content.sh`, `check_analytics_dashboard.sh`,
   `test_pulse_model.js`가 그대로 통과한다.
3. 데스크톱 1440×1000, 태블릿 768×1024, 모바일 390×844 캡처에서 겹침·잘림·가로 넘침이 없다.
4. 키보드 탭 이동과 모바일 내비게이션 열기/닫기가 동작한다.
5. 실제 Google 로그인·Supabase 데이터와 게임 실기기 동작은 이번 마케팅 페이지 범위가 아니다.
