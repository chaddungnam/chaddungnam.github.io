# House Duck Project K · 개발자 스토리 사이트 설계

- 상태: 승인됨
- 기준일: 2026-08-03
- 대상: `houseduck.in` 공개 브랜드 사이트

## 목표

Quirky Ball만 보이던 House Duck 사이트를 두 게임의 카탈로그로 확장한다. Project K는 실제
클라이언트 화면과 고유한 분위기로 소개하고, 개발자 스토리는 경력의 나열보다 왜 House Duck을
시작했는지 기억되게 전달한다. 모든 마케팅·게임 상세 페이지는 한국어·영어·독일어·일본어를
지원한다.

## 정보 구조

1. 홈
   - 첫 화면은 House Duck 브랜드를 유지한다.
   - 게임 영역에서 Quirky Ball과 Project K를 동등하게 소개한다.
   - 개발자 스토리로 이동하는 명확한 링크를 상단 메뉴와 본문에 둔다.
2. Project K 상세
   - 작업명 `Project K`, `개발 중`, `2026년 하반기–2027년 상반기 공개 목표`를 표시한다.
   - 장르는 `풍자 국가경영 시뮬레이션`으로 소개한다.
   - 플레이어가 이해할 수 있는 `결재와 이야기 → 현장과 생산 → 기술 성장 → 세계 경쟁` 흐름을
     실제 720×1280 클라이언트 캡처로 보여 준다.
   - `세로형`, 내부 시스템명, 확정되지 않은 캠페인 분량처럼 구매 판단에 도움이 안 되는 개발
     용어는 공개 문구에서 제외한다.
3. 개발자 스토리
   - `1998 → 산업디자인 → 게임업계 3년 → 한국에서 독일로 → House Duck`을 시각 타임라인으로
     보여 준다.
   - N사를 포함해 성장 단계가 다른 여러 게임사에서 회사의 성장과 전환, 성공과 좌절, QA와
     제작 노하우를 체득했다는 사실을 과장 없이 서술한다.
   - 독일어 학습과 정착이 빠듯한 조건에서도 축적한 경험으로 직접 게임 제작에 도전한 이유를
     이야기한다.
   - 가짜 인물 사진과 AI 생성 인물 이미지는 쓰지 않는다. 큰 숫자, 타임라인, 실제 제작 화면,
     인용 카드로 글의 리듬을 만든다.

## 확정 핵심 문구

### Project K

> 한 번의 결재가 나라를 웃기게도, 위태롭게도 만듭니다.

AI가 세계를 운영하는 2187년, 마지막 폐쇄국의 신임 지도자가 되어 선전과 현실 사이를 관리한다.
농장을 살리고, 현장을 순시하고, 외교와 전쟁을 결정한다. 가볍게 내린 선택도 예상하지 못한
이야기로 돌아온다.

### 개발자 스토리

제목은 `게임을 고치던 사람이, 이제 자신의 게임을 만듭니다.`로 한다. 본문은 다음 흐름을
유지하되 언어별로 직역하지 않고 자연스럽게 현지화한다.

- 1998년 한국에서 태어나 산업디자인을 공부했다.
- N사를 포함해 규모와 성장 단계가 다른 여러 게임사에서 3년간 일하며 성공과 좌절, 팀의 성장과
  전환을 가까이서 경험했다.
- QA는 버그를 찾는 일을 넘어 플레이어의 시간을 지키고 팀의 의도를 완성하는 일임을 배웠다.
- 독일로 건너와 새로운 언어를 배우는 빠듯한 생활 속에서도 직접 만들겠다는 질문을 놓지 않았다.
- `서당개도 3년이면 풍월을 읊는다`는 한국 속담을 자기비하가 아니라 축적된 관찰을 행동으로
  옮기는 전환점으로 사용한다.
- House Duck은 완벽한 조건을 기다리지 않고, 작게 시작해 하나의 게임으로 끝나지 않는 제작 방식과
  브랜드를 쌓는 도전이다.

회사명·성과·투자·매출은 확인되지 않은 구체 수치를 만들지 않는다. 다른 회사의 실패를 평가하거나
내부 정보를 암시하지 않고, 공개적으로 안전한 `성장과 전환, 성공과 좌절을 가까이서 경험했다`는
표현을 사용한다.

## 시각 방향

- House Duck 홈과 스토리: 기존 크림·네이비·코랄·틸의 밝은 편집 디자인을 유지한다.
- Project K: 실제 게임 팔레트의 먹색·암녹색·크림슨·종이색·금색으로 분위기를 분기한다.
- Project K 카드와 상세 페이지는 픽셀 테두리와 보고서/결재 문서의 위계를 차용하되, House Duck
  상단 메뉴와 접근성 규칙은 공통으로 유지한다.
- 모든 콘텐츠 이미지는 원본 종횡비를 유지한다. HTML에 실제 `width`/`height`를 기록하고 CSS는
  `width: 100%; height: auto; object-fit: contain`을 기본으로 한다. 고정 프레임이 필요한 경우에만
  래퍼에 `aspect-ratio`를 주고 이미지는 `object-fit: cover`로 자른다. 비균등 확대는 금지한다.

## 언어 동작

- 지원 언어는 `ko`, `en`, `de`, `ja` 네 가지다.
- 상단 메뉴에 네 언어를 직접 선택할 수 있는 접근 가능한 언어 선택기를 둔다. 홈, Quirky Ball,
  Project K, 개발자 스토리에서 같은 위치와 동작을 사용한다.
- 첫 방문에는 `navigator.languages`의 순서에서 처음 발견되는 지원 언어를 사용한다. 한국어는
  한국어, 독일어는 독일어, 일본어는 일본어로 이동하고 일치하는 언어가 없으면 영어로 이동한다.
- 사용자가 상단에서 언어를 선택하면 `localStorage`에 저장하며 이후에는 기기 언어보다 수동 선택을
  우선한다.
- URL의 `?lang=ko|en|de|ja`는 가장 높은 우선순위로 처리하고 같은 페이지의 해당 언어 파일로
  이동한다. 지원하지 않는 값과 저장소 차단은 영어 또는 현재 문서로 안전하게 폴백한다.
- 자동 이동은 같은 경로의 다른 언어 문서로만 이동하고 리디렉션 루프를 만들지 않는다.

## 구현 경계

- 정적 HTML, 기존 CSS, 기존 바닐라 JavaScript만 사용한다. 프레임워크와 외부 런타임 의존성을
  추가하지 않는다.
- 새 페이지: Project K 4개 언어, 개발자 스토리 4개 언어.
- 기존 페이지 확장: 홈과 Quirky Ball 상세의 독일어·일본어 문서, 네 언어 상단 선택기, 홈 게임
  카탈로그와 스토리 링크.
- 기존 약관·개인정보·콘솔·분석 대시보드 내용과 현재 다른 작업자의 미커밋 변경은 건드리지 않는다.
