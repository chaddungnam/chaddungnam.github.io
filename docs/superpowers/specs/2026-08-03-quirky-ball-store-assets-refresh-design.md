# Quirky Ball 스토어 자산 웹 반영 디자인

## 목표

House Duck 홈과 Quirky Ball 게임 페이지에서 AI풍·레거시 이미지를 제거하고,
상위 작업공간 `store_asset/QuirkyBall/Upload`의 실제 Google Play
납품 자산을 원본 비율 그대로 보여준다. 기존 앱 아이콘은 유지한다.

## 승인된 방향

- 별도 AI 이미지 생성 없이 공식 스토어 자산만 사용한다.
- 홈의 큰 장식 그림은 실제 Quirky Ball 플레이 화면을 보여주는 스토어 대표 이미지로 교체한다.
- 게임 페이지 갤러리는 최신 Phone 자산 8장을 사용하고, 원본 9:16 비율을 강제로 자르지 않는다.
- 현재 House Duck 색상·폰트·내비게이션·법적 문서 구조는 유지한다.
- 데스크톱과 모바일 모두에서 이미지가 늘어나거나 잘리지 않아야 한다.

## 검증

- 정적 계약 검사는 최신 자산 경로, 8개 스크린샷, `height: auto`, `object-fit: contain`을 확인한다.
- 브라우저 검사는 이미지의 자연 비율과 실제 표시 비율이 같은지 확인한다.
- 1440×900, 1440×760, 390×844에서 홈과 게임 페이지를 캡처해 육안 확인한다.
