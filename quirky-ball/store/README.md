# Quirky Ball 웹 이미지

이 폴더의 PNG는 상위 작업공간의 `store_asset/QuirkyBall/Upload`에서
웹 페이지에 필요한 파일만 복사한 것이다. 원본을 수정하지 말고, 스토어 자산이 승인되어
교체될 때 같은 번호와 용도의 파일을 다시 복사한다.

- `feature-graphic.png`: Google Play Feature Graphic
- `01-core.png` ~ `08-ranking.png`: Google Play Phone 스크린샷 8장
- 앱 아이콘과 로고는 상위 `quirky-ball/`의 기존 파일을 계속 사용한다.
