      가장 빠른 방법 — 앱에서 직접 삭제

      1. Quirky Ball 앱을 실행합니다.
      2. 홈 화면에서 설정으로 이동합니다.
      3. 계정 삭제를 누르고 안내에 따라 확인합니다.

      삭제가 확인되면 서버와 기기에 저장된 모든 게임 데이터가 즉시 영구적으로 삭제되며, 복구할 수 없습니다.

      앱에 접속할 수 없는 경우 — 이메일로 요청

      아래 버튼을 눌러 이메일을 보내 주세요. 닉네임과 표시 코드(앱 설정 화면 하단에서 확인 가능)를 함께 적어 주시면 본인 확인 후 합리적인 기간 내에 처리하고 결과를 회신해 드립니다.

      이메일로 계정 삭제 요청

      삭제되거나 보관되는 데이터

      데이터 유형삭제/보관 정책
      게스트 식별자(UID), 닉네임, 표시 코드, 국가앱 내 삭제 시 즉시 삭제 / 이메일 요청 시 본인 확인 후 합리적인 기간 내 삭제
      구글 계정 연동 정보(이메일, 프로필 이름)같은 절차로 삭제
      서버 계정 상태(진행, 가상 재화, 최고 점수 등)같은 절차로 삭제
      원본 플레이·시즌·주간 기록계정 삭제 요청 시 함께 삭제되며, 요청하지 않아도 생성 후 28일이 지나면 자동 삭제
      기기에만 저장되는 설정(언어, 음량, 진동, 프레임레이트 등)앱 삭제 또는 계정 초기화 시 기기에서 제거
      광고 식별자 및 스토어 거래 기록Google 또는 Apple이 각자의 정책에 따라 관리하며, 법적으로 필요한 최소 결제 기록은 필요한 기간 보관될 수 있음

      관련 법령에서 별도의 보관을 요구하는 경우에만 해당 기간 동안 보관하며, 그 외에는 삭제 후 어떤 데이터도 추가로 보관하지 않습니다.
